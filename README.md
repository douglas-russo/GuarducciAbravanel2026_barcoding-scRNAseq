This repository contains code that renders a Quarto book that reproduces the plots related to the barcoding and scRNAseq analyses from [Guarducci and Abravanel et al.  (2026)]. Specific plot colors, orientations, dimensions, label names/abbreviations, and row/column orders may differ slightly from paper figures. R package versions may differ from specific versions used in paper analyses. 

The fully rendered book contains chapters for cell line barcoding, scRNAseq, and *in-vivo* barcoding analyses and can be viewed [here](https://douglas-russo.github.io/GuarducciAbravanel2026_barcoding-scRNAseq/).

Quarto markdown documents used to render the entire book are listed as .qmd file.

Raw and processed data files related to these analyses are deposited on the NCBI’s Gene Expression Omnibus (GEO) [https://doi.org/10.1093/nar/30.1.207] under the following accession numbers: overall study [GSE325486](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE325486) and scRNA-seq [GSE326012](https://www.ncbi.nlm.nih.gov/geo/query/acc.cgi?acc=GSE326012).
